# ShopGuard AI

تطبيق محلي لمراقبة محل تجاري عبر كاميرا الحاسوب أو فيديو مسجّل. الواجهة بالدارجة المغربية، وكتجمع الفيديو والتنبيهات والمراجعة فصفحة وحدة.

## التشغيل

المتطلبات: Python 3.10 أو أحدث.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py --port 8001
```

إلا كانت البيئة موجودة وكتستعمل `uv`:

```powershell
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
.\.venv\Scripts\python.exe app.py --port 8001
```

حل [التطبيق](http://127.0.0.1:8001/). نماذج `yolo11n.pt` و`yolo11n-pose.pt` كيتحمّلو فالتشغيل الأول؛ تقدر تحطهم فجذر المشروع باش تخدم بلا إنترنت. راجع [ترخيص Ultralytics](https://www.ultralytics.com/license) قبل التوزيع التجاري.

## الاستعمال

- **فيديو مسجّل:** اختار MP4 أو MOV أو AVI أو WebM أصغر من 150 MB، حدّد المنطقة فوق المعاينة، واضبط مدة البقاء. MP4 بترميز H.264 هو الأفضل للتشغيل فالمتصفح.
- **كاميرا مباشرة:** اضغط الزر وسمح للمتصفح بالوصول. يمكن اختيار كاميرا الحاسوب أو USB. المعالجة محلية والصوت مطفي. الكاميرات عبر RTSP ما مدعومينش حالياً.
- **المراجعة:** كل تنبيه كيعرض السبب والتوقيت. 1 لتأكيد الحدث، 2 للتنبيه الخاطئ، وCtrl+Z للتراجع عن آخر قرار جديد. الحدث غير الواضح يقدر يبقى معلّق.
- **أدوات المراجعة:** العرض البطيء، إعادة المقطع، توسيع السياق، وخطوات حسب توقيت الإطارات. أحداث الكاميرا كتوفّر صورة ثابتة؛ البث الخام ما كيتسجلش.

الكاميرا كتحتاج localhost أو HTTPS. إلا المتصفح المضمّن ما سمحش بالوصول، جرّب Chrome أو Edge. تحليل الكاميرا والملفات كيتشاركو نفس المحرك، وكيخدم غير مصدر واحد فكل مرة.

## كيفاش كتتولد التنبيهات

YOLO كيكشف الأشخاص، وByteTrack كيتبعهم داخل نفس المشهد. تنبيهات المراجعة كتستعمل مدة البقاء، الرجوع المتكرر للمنطقة، وبعض حركات اليد ملي تكون نقاط الجسم واضحة. كل إشارة كتحتافظ بمعطياتها وقت التسجيل. تبدّل المشهد كيبدأ تتبع جديد.

النظام كيرصد نشاطاً للمراجعة، وما كيأكدش السرقة ولا هوية الأشخاص. ثقة كشف الشخص ماشي احتمال السرقة. الحجب، ضعف الإضاءة والدقة المنخفضة يقدرو يأثرو على النتائج. قياس دقة تصنيف السرقة كيحتاج فيديوهات عادية وأحداث معلّمة زمنياً؛ أسماء الملفات ما كتعتبرش وسوماً.

## الملفات

- `app.py`: السيرفر، SQLite وواجهات API.
- `processing.py`: معالجة الفيديوهات المسجّلة.
- `live.py`: جلسات الكاميرا المباشرة.
- `vision.py`: التتبع وإشارات النشاط.
- `static/`: الواجهة.
- `tests/`: اختبارات المنطق والتخزين والمعالجة.
- `scripts/`: فحص الفيديوهات وقياس الأداء واستيراد النتائج.

الفيديوهات كيتخزنو فـ `data/uploads/`، صور التنبيهات فـ `data/snapshots/`، والبيانات فـ `data/shopguard.db`. المجلد محلي، وما كاينش حذف تلقائي. استعمل فيديوهات بموافقة المشاركين وحدد مدة احتفاظ مناسبة. هاد النسخة مخصّصة للاستعمال المحلي، وما فيهاش حسابات مستخدمين أو إعدادات نشر عمومي.

## التحقق والتنسيق

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --check static/app.js
node --check static/review.js
node --check static/camera.js
```

اختبارات الكاميرا كتستعمل صور JPEG مولّدة ومعالجة حقيقية بالنماذج، بلا فتح كاميرا الجهاز. للاختبار اليدوي بمعطيات مفصولة:

```powershell
.\.venv\Scripts\python.exe tests/serve_ui_fixture.py
```

إعدادات التنسيق موجودة فـ `pyproject.toml` و`.prettierrc.json`. تبعيات التطوير موجودة فـ `requirements-dev.txt`.

```powershell
ruff format app.py vision.py processing.py live.py scripts tests
prettier --write static
```

سكريبتات الفيديو كتقبل `--directory`، وقياس الأداء كيقبل `--video`. نتائج التحقق كتخزن فـ `data/validation/`؛ قياس السرعة ما كيقيسش دقة الكشف.
